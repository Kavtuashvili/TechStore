# 🛒 TechStore

A simple e-commerce website built with PHP, MySQL, HTML, CSS and JavaScript.

## 🚀 Features

* Product catalog
* Product details page
* Shopping cart
* Checkout system
* Order history
* User authentication
* Admin dashboard
* Product management
* Order management

## 🧱 Tech Stack

* PHP
* MySQL
* HTML5
* CSS3
* JavaScript
